# RevGT – Car Dealership Web Platform

RevGT is a full-stack car dealership web platform developed as a university group project for a Web Programming course. The website presents dealership information, vehicles, and services through a multi-page interface.

The project combines a frontend built with HTML, CSS, and JavaScript with PHP functionality and a MySQL database.

## Features

- Multi-page website with home, about, and contact pages
- Vehicle and service information
- Login and logout functionality
- PHP-based server-side functionality
- MySQL database integration
- Interactive elements and page transitions

## Technologies

- **HTML5** — page structure
- **CSS3** — layout and styling
- **JavaScript** — interactive frontend behaviour
- **PHP** — server-side functionality and database integration
- **MySQL** — data storage and queries
- **jQuery** — visual effects and transitions

## Getting Started

The project requires a local PHP web server and a MySQL database. XAMPP can be used to run it locally.

1. Clone or download this repository.
2. Place the project folder in your local server directory, such as `htdocs` in XAMPP.
3. Start **Apache** and **MySQL** from the XAMPP Control Panel.
4. Import the project database into MySQL, if a database export is included.
5. Configure the database connection in the PHP files for your local environment.
6. Open the project through your local server, for example: `http://localhost/Ueb_g23/`.

## Project Context

RevGT was created as a university group project to practise full-stack web development, including frontend development, PHP, and relational database integration. It is an educational project and is not affiliated with a real car dealership.
