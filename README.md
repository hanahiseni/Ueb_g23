# Ueb_g23
Ky projekt është realizuar në kuadër të lëndës Programimi ne Ueb nga ana e Klientit, me qëllim demonstrimin praktik të njohurive në HTML5, CSS/CSS3 dhe JavaScript, duke respektuar standardet moderne të zhvillimit të faqeve ueb.
Projekti përbëhet nga një faqe kryesore dhe disa faqe funksionale, të cilat ofrojnë përmbajtje informative, ndërveprim me përdoruesin dhe elemente dinamike përmes JavaScript-it.

Teknologjitë e Përdorura
HTML5 për strukturimin e përmbajtjes
CSS2 dhe CSS3 për dizajnin vizual dhe paraqitjen grafike
JavaScript (ES6+) për funksionalitete dinamike
jQuery për efekte vizuale dhe tranzicione

Ky projekt demonstron përdorimin korrekt të teknologjive bazë të zhvillimit ueb, duke përmbushur kërkesat funksionale dhe teknike të lëndës. Struktura e projektit është e organizuar, dizajni është modern dhe funksionalitetet dinamike rrisin ndërveprimin me përdoruesin.
